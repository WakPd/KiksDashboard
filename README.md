# 🎯 KiksDashboard

Dashboard multifonctionnel moderne avec Portfolio, Finance et Gestion de Parfums.

## 🚀 Démarrage Immédiat

**Aucune installation requise !**

1. Téléchargez les fichiers
2. Double-cliquez sur `webapp.html`
3. L'application s'ouvre dans votre navigateur

## 🌐 Démo en Ligne

**Version de Test:** [https://votreusername.github.io/KiksDashboard/webapp.html](https://votreusername.github.io/KiksDashboard/webapp.html)

## ✨ Fonctionnalités

### 📋 Portfolio
- CV interactif avec animations
- Modification en direct
- Sections : Expériences, Formation, Compétences

### 📈 Finance  
- Suivi d'actifs boursiers
- Interface intuitive
- Données sauvegardées automatiquement

### 🌸 Parfums
- Gestion de collection
- Recommandations météo
- Filtres par type

## 🎨 Technologies

- HTML5 + CSS3
- JavaScript Vanilla
- Tailwind CSS (CDN)
- Font Awesome (icônes)
- LocalStorage (sauvegarde)

## 💾 Sauvegarde

Toutes vos données sont sauvegardées automatiquement dans votre navigateur (localStorage).

## ✏️ Personnalisation

### Via l'Interface
Cliquez sur "Modifier" dans le Portfolio pour changer vos informations.

### Via le Code
Ouvrez `app.js` avec un éditeur de texte et modifiez les données initiales (lignes 2-40).
